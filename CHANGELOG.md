# Changelog

All notable changes follow Semantic Versioning and Keep a Changelog conventions.

## [0.1.0-rc.2] - 2026-07-30

### Added

- Cross-platform one-click local lifecycle and a seven-persona, ordered 30-step player
  lifecycle gate.
- Complete deterministic asset-production workflow with manifest order, responsive
  variants, provenance, visual-review gates, runtime synchronization and release blocking.
- Real seeded-application Google Play, iPhone and iPad capture automation at exact accepted
  dimensions, plus store/community readiness evidence.
- Integer-only four-season balance simulation for 100 players, 500 companies and ten
  cartels, with versioned Season 0 configuration and exploit regression tests.
- Protected production metrics, machine-readable alert definitions, safe staging/production
  smoke scripts, isolated restore drill and final release evidence runner.
- Mobile API configuration enforcement, unsigned all-platform preview export proof and
  explicit signing/device/submission operator gates.
- Localized verification/reset mail, shared abuse limits, SMTP production validation and
  provider activation checklist.

### Security

- Privacy export retains exact monetary strings; account deletion pseudonymizes identity,
  revokes sessions/tokens/invites/outbox data and preserves immutable finance/audit history.
- Standalone masked secret scanning, Bandit/pip/pnpm audit evidence, dependency-license
  review and repository-local documentation link validation.
- Production `/metrics` now requires a dedicated bearer token and remains undiscoverable
  without valid authorization.

### Changed

- Accessibility coverage expanded to all 31 primary routes on desktop and mobile, with
  Critical/Serious Axe findings fixed and human device/screenreader checks kept external.
- Google Play and Apple store-art contracts now use exact current pixel dimensions instead
  of generic aspect-ratio defaults.
- Release completion distinguishes repository/local proof from production deployment,
  provider activation, signed store builds, legal approval and physical-device evidence.
