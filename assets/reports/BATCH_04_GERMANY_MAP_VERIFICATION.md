# Batch 04 — Germany map verification

## Result

All twelve `germany-map` assets are approved and integrated:

- four licensed BKG geography SVGs,
- three deterministic map backgrounds,
- five deterministic heatmap legends.

The authenticated web application exposes them at `/germany` through the
localized `Germany` / `Deutschland` navigation item. The page is explicitly a
geographic reference view and does not infer or compute authoritative gameplay
state.

## Licensed geography

The reproducible builder is
`scripts/assets/build-germany-map.mjs`. Raw WFS responses and the complete
machine-readable provenance record are stored below
`assets/source/maps/geodata/bkg-2025/`.

| Asset | Official input | Selection | Output |
| --- | --- | --- | --- |
| `map-germany-outline-v1` | BKG VG250, status 01.01.2025 | State areas with `GF=4` | 79,997-byte SVG |
| `map-federal-state-borders-v1` | BKG VG250, status 01.01.2025 | Boundaries with `AGZ=2 AND GMK=0` | 70,581-byte SVG |
| `map-coasts-water-v1` | BKG VG250 and DLM250, status 31.12.2025 | Coastlines, river surfaces, lakes ≥1 km² | 73,096-byte SVG |
| `map-major-rivers-v1` | BKG DLM250, status 31.12.2025 | Water surfaces and axes selected by canonical `GWK` identifiers | 75,041-byte SVG |

All inputs use EPSG:25832 and all outputs share a north-up
`0 0 1536 1536` view box. The SVG validation rejects raster payloads, scripts,
external resources, incorrect dimensions, and files over 100 KB.

The first river proof used only a width class and was rejected during visual
review because it produced disconnected fragments. The accepted derivation
combines broad rivers represented as official water surfaces with narrower
official axes selected by stable watercourse identifiers. No geographic shape
was generated by image AI.

## License and attribution

License: [Data licence Germany – attribution – version 2.0](https://www.govdata.de/dl-de/by-2-0).

The application visibly renders both required notices next to the map:

```text
© BKG 2025 dl-de/by-2-0 (Daten verändert), Datenquellen:
https://sgx.geodatenzentrum.de/web_public/gdz/datenquellen/datenquellen_vg_nuts.pdf

© GeoBasis-DE / BKG 2025 dl-de/by-2-0 (Daten verändert)
```

`BKG`, the license, and the source record are clickable. Per-asset review JSON,
input hashes, output hashes, feature counts, WFS queries, and simplification
tolerances are retained in `assets/reports/reviews/`, asset metadata, and
`assets/source/maps/geodata/bkg-2025/sources.json`.

## Procedural visual system

The day, night, and neutral backgrounds use the same restrained grid and
contour geometry with distinct luminance and color temperature. The five
heatmap legends use discrete swatches plus one through five dots, so intensity
is not encoded by color alone. No legend contains embedded labels; English and
German labels remain canonical application text.
